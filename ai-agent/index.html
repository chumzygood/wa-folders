Let your AI agent use your WhatsApp folders

New in WA Folders 1.3.1: your AI agent (Claude Desktop, Cursor, Codex or any MCP app) can list your WhatsApp Web folders, search them, read your notes and summarize a chat, all on your own computer. Free to try. Pro is a one-time $4.99 payment, no subscription.

Add to Chrome, freeDownload the agent bridge

Version 1.3.5, with a simpler first run, is live on the Chrome Web Store. Chrome updates the extension automatically.

What your agent can do

  • Ask: "What's in my Clients folder?", "Who mentioned the invoice?", "Summarize my chat with Ana."
  • Get context automatically: each folder you allow is offered as a short digest (chat names, notes, reminders, recent lines) that agents can attach without asking.
  • Organize (only if you allow it): add a chat to a folder or set a reminder.

What it can never do

Send, delete or open WhatsApp messages, or see folders you didn't tick. There is no WA Folders server: the extension and the bridge talk over a local connection on your computer, with no internet calls.

Set it up in 3 steps

  1. Install Node.js 18 or newer, unzip the bridge and run install-windows.ps1 (Windows) or bash install-mac-linux.sh (Mac).
  2. In WA Folders, open Settings > AI agent access, turn it on and tick the folders the agent may use.
  3. Add the MCP server the installer prints to your agent, for example in Claude Desktop:
    {"mcpServers":{"wa-folders":{"command":"node","args":["<path>/wa-folders-agent.js"]}}}

Revoke any time with Revoke all agent access. Details in the privacy policy.
