# WA Folders

Chrome extension for [WhatsApp Web](https://web.whatsapp.com): folder tabs, local search, chat export, follow-up reminders that clear when someone replies, and voice notes to text. Data stays in your browser. There is no WA Folders account or server, and it never presses Send.

**Install:** [WA Folders on the Chrome Web Store](https://chromewebstore.google.com/detail/wa-folders/hahfpdlfieloofgjhanljbbnakinfhil)

**Site:** [https://chumzygood.github.io/wa-folders/](https://chumzygood.github.io/wa-folders/) · [Português (Brasil)](https://chumzygood.github.io/wa-folders/pt-br/) · [vs WhatsApp Lists](https://chumzygood.github.io/wa-folders/compare/)

Current store version: **1.2.9** (updated Oct 11, 2026). Made by Chanoch Kamelhar (`ckamelhar@gmail.com`). Not affiliated with WhatsApp or Meta.

## What it does

- **Folder tabs** above your chat list (Family, Work, Clients, or your own), with unread, reply, question and due markers
- **Needs reply / Questions for me / Waiting on them** lists, plus reminders that clear themselves when the other person answers
- **Search** chat names, your notes, and messages WA Folders has seen; filter by folder, notes or links
- **Export** the open chat to HTML, CSV, Markdown or JSON
- **Voice notes to text** and **translate** (Portuguese, English, Spanish) — on your computer by default
- **Privacy blur**, quick replies that fill the message box without sending, optional Catch me up / Draft a reply

Works only on WhatsApp Web in Chrome on a computer. It does not work in the WhatsApp phone app.

## Free and Pro

Free plan, no time limit: 5 folders, 5 search results, 3 exports a day, plus small daily allowances for transcription, translation, reminders, quick replies, rules, AI answers and the deal board.

Pro is a one-time $4.99 unlock (paid through Polar, no subscription). Try Pro free for 7 days from inside the extension (no card). Upgrade from any limit message or the toolbar popup, then paste your license key (starts with `WAF-`).

## Privacy in one line

Folders, notes, reminders and search live in `chrome.storage.local` on this computer. AI, transcription and translation run on-device by default. Optional API keys and the Pro license check never send chat content to WA Folders (there is no WA Folders server).
