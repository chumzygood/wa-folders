How to export a WhatsApp Web chat, and what ends up in the file

Updated October 13, 2026 · WA Folders 1.2.9

You're on https://web.whatsapp.com, you need a copy of one conversation (an order thread, a landlord chat, a group decision), and you're looking for an export button in the browser. WhatsApp's own export is documented for the phone app. This post covers that method first, then a way to do it from WhatsApp Web in Chrome.

Option 1: Export chat in the WhatsApp phone app

WhatsApp's help page "How to export your chat history" has steps for Android and iOS. For Android it says:

  1. Open the chat.
  2. Tap More options > More > Export chat.
  3. Tap Without media or Include media.
  4. Choose how to send it, for example by email or to a notes app.

For iPhone, use the iOS tab on the same help page.

The same page notes that Include media attaches the most recent media, and that the export can't be re-imported into WhatsApp because it's a text file, not a backup. If you need the media files themselves, start with the phone.

Option 2: Export from WhatsApp Web with WA Folders

I built WA Folders, a Chrome extension that runs only on https://web.whatsapp.com. It doesn't work in the phone app or the desktop app, it never sends messages, and it isn't affiliated with WhatsApp or Meta. Exports are built in your browser and saved as a normal download. Nothing goes to a WA Folders server; there isn't one.

Steps

  1. Install WA Folders: https://chromewebstore.google.com/detail/hahfpdlfieloofgjhanljbbnakinfhil?utm_source=site&utm_medium=guide
  2. Open https://web.whatsapp.com and open the chat you want.
  3. In the WA Folders panel, under This chat, find the line that starts "Export". On the free plan it reads "Export · 0/3 today · messages loaded on screen".
  4. Click HTML, CSV, Markdown or JSON. The file downloads as WhatsApp - <chat name> - <date>.<ext>, and the panel confirms how many messages it took, for example "Exported 6 messages that were loaded on screen. Use Load whole chat to include everything."

What the file contains (free plan)

A normal export covers the messages loaded on screen in that chat. WhatsApp Web loads a chat in pieces as you scroll, so to include older messages in a free export, scroll up in the chat first. As a technical limit on every plan, one export of the open chat keeps the newest 5,000 loaded messages.

Each message comes with the sender ("You" for your own messages), the time when WhatsApp shows it, and the text. In detail:

  • Media is labelled. Photos, videos, voice notes, files and stickers appear as [photo], [video], [voice message], [file] or [sticker]. A photo with a caption keeps both the label and the caption. The media files themselves aren't in the export.
  • Replies come out right. When someone replies to a message, the export shows their reply under their name. The message they quoted isn't copied in as if they wrote it.
  • Group chats use the group name as the title, and each message has the member's name.
  • Your private note for that chat, if you wrote one in WA Folders, is included in HTML, Markdown and JSON. CSV has four columns, direction, time, sender and text, and no note.
  • CSV is UTF-8 with a byte-order mark and Windows line endings, so Excel shows accents and emoji correctly. Where your system uses a comma as the decimal mark (Brazil, most of Europe, Indonesia), the columns are separated with semicolons so Excel splits them. Cells that start with =, +, - or @ get a leading apostrophe so a spreadsheet doesn't run them as formulas.
  • HTML looks like a chat, with your messages on the right, and opens in any browser. JSON has the chat name, the export time, your note and a list of messages.

Here is a demo chat exported to Markdown, opened in a Markdown viewer. The bakery's reply quoted my earlier message, and the export shows it as the bakery's own text. The photo I sent shows as [photo].

The free plan allows 3 exports a day, counted on your computer and reset at local midnight. Each file counts as one. When you've used them, the buttons grey out and the panel says "Free plan: 3 exports a day, resets at midnight." with an Upgrade link.

What Pro adds

Pro removes the limits for a one-time payment of $4.99.

  • Unlimited exports. The counter shows how many you've made today, with no limit.
  • Load whole chat. It keeps scrolling the open chat to the top so WhatsApp loads older messages, collects them as it goes, and stops when nothing new arrives for a few seconds or when you press Stop. A technical limit stops it at 20,000 messages. If you open another chat while it runs, it stops and collects nothing, so two chats never end up in one file. It can only collect what WhatsApp Web can load.
  • Whole-folder export. One file for every chat in a WA Folders folder, with each chat's note. It warns you first: it opens each chat in turn, so WhatsApp marks them as read, and it takes what loads on screen for each one. One run opens up to 100 chats, a technical limit. It has a Stop button and reopens the chat you were in.
  • Password-protected files. Tick "Password-protect exports" and type a password of at least 8 characters. The export becomes a single HTML file encrypted with AES-GCM, using a key derived from your password. It opens in any browser once you type the password. The password isn't saved anywhere, so if you lose it, the file can't be opened.

Which one to use

Use the phone's Export chat when you want the media files or a file WhatsApp itself produced. Use WA Folders when you're already in the browser and want a readable HTML page, a spreadsheet you can filter, Markdown for your notes, or JSON for a script.

FAQ

Can I export a WhatsApp Web chat without an extension? WhatsApp's export help page covers the phone apps. On the computer you can copy messages by hand, or use Export chat on your phone.

Why does my WA Folders export have fewer messages than the chat? A normal export only takes what's loaded on screen. Scroll up first, or on Pro use Load whole chat.

Does exporting notify the other person? No. The file is made in your browser. The one side effect is the Pro folder export, which opens each chat, and WhatsApp marks opened chats as read.

Can I import the file back into WhatsApp? No. WhatsApp's help page says its own export can't be re-imported, and a WA Folders export is a copy for reading too, not a backup.
