WhatsApp shared chat themes: who changed your chat wallpaper, and how to change it back

Published November 20, 2026

If a chat on your phone suddenly has a new wallpaper and different bubble colors, someone in that chat probably shared their theme with everyone. WhatsApp is starting to let one person set a chat theme for the whole conversation. The chat shows a system message naming who changed it, and you can pick a different theme afterwards.

Until now, chat themes were private. WhatsApp's February 2025 announcement said "your chat themes are only visible to you." That's changing in the beta.

Where this is rolling out

WABetaInfo reported on November 20, 2026 that shared chat themes are reaching some testers on WhatsApp beta for Android 2.26.46.8, from the Google Play Store. More accounts should get it over the coming weeks. WhatsApp hasn't said when everyone will have it.

On iPhone, WABetaInfo found the same option in WhatsApp beta for iOS 26.37.10.16. At the time of that report it was still in development and not available to beta testers.

So if you're on a regular, non-beta version of WhatsApp, you most likely can't share a theme yet. WABetaInfo doesn't say what people on older versions see when someone else in the chat shares one.

How to share a chat theme with everyone (Android beta)

These steps follow WABetaInfo's walkthrough of the Android beta:

  1. Open the chat or group.
  2. Tap the three-dot menu at the top right and choose Chat theme.
  3. Pick a theme or a wallpaper. You can use one of WhatsApp's themes or a photo from your gallery.
  4. A sheet opens asking who should see it. Choose the option to apply it for everyone.

WhatsApp then sets the same wallpaper and bubble color on both sides of the chat and adds a system message saying the theme was changed for everyone. The other person doesn't have to accept anything.

If you only want the new look on your own phone, pick the option to keep it to yourself instead. That keeps it private, as themes were before.

Someone changed the theme in my chat. Who did it?

Scroll to the point in the conversation where the look changed and find the system message there. WABetaInfo says it tells everyone who shared the theme. In a group, that's how you find out which member did it.

How to change it back

According to WABetaInfo, you aren't stuck with a theme someone else shared. Open the same Chat theme page for that chat and choose a different theme or wallpaper.

Two things to keep in mind:

  • If you choose to apply your new pick for everyone, you change the chat for the other person or the whole group too, and your name shows in the system message.
  • WABetaInfo doesn't say whether a theme you set only for yourself stays in place if someone shares a new theme later. If it gets replaced, set it again.

To go back to WhatsApp's default look for all your chats, the setting is under Settings > Chats (WhatsApp's blog calls it Default chat theme). That changes your default for all chats.

Shared themes in groups

The feature works in group chats too. When one member shares a theme, every member sees the same wallpaper and bubble color, and the system message names who did it. WABetaInfo says any member of the group can update the theme at any time. Its report doesn't mention a setting that limits this to admins.

In a large group, that means one person can change the look for hundreds of people. If that becomes a problem, the system message tells you who to talk to.

Think twice before sharing a photo as wallpaper

Shared themes aren't limited to WhatsApp's preset designs. You can share any image from your gallery as the wallpaper, and everyone in the chat will see it behind their messages. That's fine for a family photo in a family group. In a work group or a big community group, it puts your photo on other people's screens.

WABetaInfo says the shared theme is end-to-end encrypted, so WhatsApp can't see which wallpaper you picked. The people in the chat can see it.

What about WhatsApp Web?

WhatsApp Web started rolling out its own chat themes to some beta users in October; we covered that in WhatsApp Web chat themes. Those themes are personal. Only you see them.

Neither WABetaInfo report mentions shared themes on WhatsApp Web or the Windows app, or says how a shared theme will show up there. Don't assume a theme shared from a phone will show up on your computer.

Don't see the option?

The feature is only on the Android beta, and not every tester on 2.26.46.8 has it. If you want to try it early, how to join the WhatsApp beta walks through signing up. Otherwise, wait for the regular update.

FAQ

Can other people see my WhatsApp chat theme? Only if you choose to apply it for everyone, and only once the shared themes feature reaches your account. A theme you keep to yourself stays visible only to you.

Does the other person get a notification when I share a theme? WABetaInfo describes a system message in the chat that says who changed the theme. It doesn't mention a separate push notification.

Can I stop group members from changing the theme? WABetaInfo says any group member can change it, and its report doesn't describe an admin control for this.

Is shared chat theme available on iPhone? WABetaInfo found it in development in WhatsApp beta for iOS 26.37.10.16, but it wasn't available to testers yet.
