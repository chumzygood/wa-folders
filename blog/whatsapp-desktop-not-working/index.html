WhatsApp Desktop not working on Windows? What to try, in order

Published November 20, 2026

If WhatsApp Desktop isn't working on Windows, quit and restart it, update it from the Microsoft Store, check your connection, and then repair or reset the app in Windows Settings, using WhatsApp Web in your browser until it's fixed.

Your chats aren't stored only in the desktop app. It's a linked device, so your phone still has your messages while you work through the steps below. Start at the top; the first few take a minute each.

First, find out where the problem is

Two checks tell you whether to fix the app, your connection or nothing at all.

  1. Does WhatsApp work on your phone? If messages won't send there either, the problem is your phone's connection or WhatsApp itself, and nothing you change on the computer will help.
  2. Does web.whatsapp.com work on the same computer? Open it in Chrome, Edge or Firefox and link it with the QR code. If Web works and the desktop app doesn't, the problem is the app, so go through steps 1, 2, 5 and 6. If Web fails too, start with the network in step 4.

Also look at the top of the desktop app. WhatsApp's connection help page says a yellow banner reading Computer not connected means the computer may not have an active internet connection.

1. Quit WhatsApp completely and open it again

Closing the window doesn't always stop the app. Press Ctrl + Shift + Esc to open Task Manager, select WhatsApp, click End task, then open WhatsApp from the Start menu. Quitting and restarting WhatsApp Desktop is the first fix WhatsApp's own help page lists once your internet connection checks out.

2. Update WhatsApp and check your Windows version

WhatsApp says to use the most up-to-date version of the app. Microsoft says the Microsoft Store updates apps automatically, and you can check for and install updates yourself from Downloads or your Library in the Store, even while automatic updates are paused.

While you're there, check that your PC can run the app. According to WhatsApp's download page, WhatsApp Desktop needs Windows 10.1 64-bit, version 1903 or later. On anything older, WhatsApp's answer is to update Windows or use WhatsApp Web. Microsoft also notes that support for Windows 10 ended on October 14, 2025, so a Windows 10 PC no longer gets free security fixes from Windows Update.

3. Restart the computer

WhatsApp suggests turning the device off, waiting 30 seconds and turning it back on. Use Restart rather than Sleep, so pending Windows and app updates can finish.

4. Try another network

WhatsApp's help page says office and university Wi-Fi can cause connection problems, and suggests trying a different network or a phone hotspot. If you manage the network yourself, WhatsApp recommends letting traffic to "web.whatsapp.com" and ".whatsapp.net" through. A VPN or proxy can get in the way too, so pause it while you test.

If WhatsApp Web is also stuck, our guide to WhatsApp Web stuck on Loading your chats covers the browser side.

5. Log out and link the computer again

WhatsApp's next suggestion is to log out of WhatsApp Desktop and log back in. If the app is too broken to reach its own settings, log it out from your phone:

  • Android: three-dot menu, then Linked devices.
  • iPhone: Settings, then Linked devices.

Tap the Windows device, tap Log out, then open WhatsApp Desktop and link it again with the QR code. Keep your phone online and WhatsApp open on it while the first sync runs.

6. Repair the app, then reset it

Windows can repair an app without reinstalling it. Microsoft's steps on Windows 11:

  1. Open Start > Settings > Apps > Installed apps.
  2. Click the three dots next to WhatsApp, then Advanced options.
  3. Click Repair. If that doesn't help, click Reset.

On Windows 10 the path is Settings > Apps > Apps & features, then WhatsApp > Advanced options.

Reset deletes the app's data on that computer, so you'll be logged out and need to scan the QR code again. Your messages are still on your phone.

7. Reinstall from the Microsoft Store

If repair and reset don't fix it, uninstall WhatsApp, restart, and install it again from the Microsoft Store, which is where WhatsApp's help page sends Windows users. Don't download a "WhatsApp for PC" installer from anywhere else. WhatsApp's linked devices page warns that linking your account to an unofficial app or website can get it temporarily or permanently banned.

If the window looks broken: plain text, raw buttons, blank screen

A couple of Windows users posted on X on November 18 and 19, 2026 that WhatsApp Desktop had suddenly turned into plain text and bare buttons, and one asked whether it was down. We couldn't confirm an outage, and WhatsApp hadn't posted anything about one. If you see this, work through steps 1, 2, 5 and 6 in that order. If WhatsApp Web looks normal in your browser, use it while the app is broken.

If it logged you out on its own

That isn't always a fault. WhatsApp's linked devices page says linked devices keep working without your phone online, but they log out if you haven't used your phone in 14 days, and WhatsApp disconnects linked devices after 30 days of inactivity. Linking again fixes it. If WhatsApp Web keeps signing you out, see why WhatsApp Web keeps logging out. If the app works but stays silent, see WhatsApp Web notifications not working.

Using WhatsApp Web in the meantime

WhatsApp Web at web.whatsapp.com counts as one of your linked devices, alongside the desktop app. WhatsApp lets you link up to four devices to one account, so you can link the browser without unlinking the broken app.

FAQ

Why is WhatsApp Desktop not opening on Windows?

Usually a stuck process or an out-of-date app. End WhatsApp in Task Manager and open it again, update it from the Microsoft Store, and restart the PC. If it still won't open, use Repair, then Reset, under Settings > Apps > Installed apps > WhatsApp > Advanced options.

Will I lose my chats if I reset or reinstall WhatsApp Desktop?

Reset and reinstall remove the app's data on that computer and log it out. Your messages are still on your phone, and you link the computer again with the QR code.

What Windows version does WhatsApp Desktop need?

WhatsApp says the Windows app needs Windows 10.1 64-bit, version 1903 or later. On older versions, update Windows or use WhatsApp Web in your browser.

Is WhatsApp Desktop down right now?

We couldn't confirm any outage for November 2026. If WhatsApp Web and your phone also fail, the problem is your connection or WhatsApp's service. If only the desktop app fails, fix the app with the steps above.

Can I use WhatsApp Web while the desktop app is broken?

Yes. WhatsApp Web is a separate linked device, and WhatsApp allows up to four, so you can link web.whatsapp.com without removing the desktop app.
