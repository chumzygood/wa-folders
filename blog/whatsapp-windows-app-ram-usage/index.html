WhatsApp for Windows using too much RAM? Why, and what to try

Published November 23, 2026

The WhatsApp app for Windows uses a lot of RAM because it loads web.whatsapp.com inside Microsoft's WebView2 browser engine, so you are running a second browser for one chat app; WhatsApp Web in a browser you already keep open usually costs less memory, with one trade-off: WhatsApp says the desktop app syncs more of your old message history.

Windows Latest put numbers on this twice this month, and Microsoft mentioned WhatsApp in a memory post in between. Everything below comes from those articles, Microsoft's and Google's documentation and WhatsApp's Help Center, all read on November 23, 2026.

Why the Windows app is heavy

According to Windows Latest, Meta replaced the native WhatsApp app for Windows in November 2025 with a version that "simply loads web.whatsapp.com inside Microsoft Edge WebView2." WebView2 is the Edge engine packaged for other apps. Microsoft's own WebView2 performance guide says it "uses Edge's multi-process architecture, so each control launches multiple browser engine processes that add memory and startup overhead."

So the app carries its own browser processes (a renderer, a GPU process, a manager) even when Edge or Chrome is already open on the same PC. Mac users still get a native WhatsApp app, Windows Latest notes.

What Windows Latest measured

Test (Windows Latest, Windows 11 laptop) RAM
WhatsApp for Windows, scrolling chats (Nov 2) 2,157.8 MB across 10 processes
WhatsApp Web in an Edge tab (Nov 2) about 700 MB
Two WhatsApp accounts in two Edge tabs (Nov 2) 593.4 MB + 562.8 MB
WhatsApp for Windows after the Nov update, before login (Nov 12) 562.2 MB
Same app, slowly scrolling one chat (Nov 12) about 1.5 GB

These are one reviewer's tests on one PC, with a media-heavy account. The same reviewer found text-only chats stayed under 1 GB, and some readers told them the app never passed 700 MB. Treat the table as a direction, not a promise for your PC.

On November 3, Microsoft's Windows Experience Blog said: "WhatsApp is seeing double digit memory improvement in their Windows app." The post gives no before or after figure. Windows Latest's November 12 retest after the update is the 562.2 MB and 1.5 GB rows above.

How to check what WhatsApp uses on your PC

  • The Windows app: open Task Manager, find WhatsApp under Apps and expand it. The group includes its WebView2 processes, which is where most of the memory sits.
  • WhatsApp Web in Chrome: Google's Chrome performance help shows how to turn on Show tab memory usage (Settings > Appearance, under Tab hover preview card on Windows). Then hover over the WhatsApp tab.
  • WhatsApp Web in Edge: Windows Latest used Edge's Browser Task Manager for its tab figures.

Measure the same thing both ways, for example ten minutes of scrolling the same chat, or the comparison won't mean much.

Switching to WhatsApp Web: what changes

Less history on the computer. WhatsApp's message history page says "WhatsApp Desktop syncs more message history than WhatsApp Web," and that to see or search your full history you should check your phone. If you search old chats on the computer often, that is a real cost. Our guide to WhatsApp Web not showing old messages covers what Web can and can't load.

Calls still work. Windows Latest reports that voice and video calls came to WhatsApp Web in July, rolling out gradually. See how to make voice and video calls on WhatsApp Web.

Tabs can be put to sleep. Chrome's Memory Saver deactivates tabs you aren't using, though Google lists page notifications and pinned tabs among the things that can keep a tab active. To be sure, add web.whatsapp.com under Always keep these sites active in Settings > Performance. Microsoft's November 3 post says Edge now puts inactive tabs to sleep after 15 minutes by default. If messages arrive late on Web, check why WhatsApp Web notifications aren't working.

Windows Resume opens the app. Windows Latest notes that Windows 11's Resume feature for WhatsApp always opens the desktop app, so it won't hand off to a browser tab.

To switch, open web.whatsapp.com, then on your phone open Linked devices and scan the QR code. The desktop app and the browser each count as one linked device, so you can keep both while you compare. If the app is misbehaving rather than slow, WhatsApp Desktop not working has the repair steps.

Thinking about a third-party desktop client instead? Read what WhatsApp says about unofficial desktop apps like ZapFast first.

FAQ

Why does WhatsApp for Windows use so much RAM?

The app loads web.whatsapp.com inside Microsoft Edge WebView2, according to Windows Latest. Microsoft's WebView2 guide says each WebView2 control starts several browser engine processes, which add memory and startup overhead.

Is WhatsApp Web lighter than the WhatsApp desktop app?

In Windows Latest's November 2 test, a WhatsApp Web tab in Edge used about 700 MB while the Windows app passed 2 GB. Results depend on your chats and PC, so measure both on your own machine.

Did Microsoft fix WhatsApp's memory use?

Microsoft said on November 3, 2026 that WhatsApp is seeing a double-digit memory improvement in its Windows app, without giving numbers. Windows Latest's retest on November 12 still saw 562.2 MB before login and about 1.5 GB while scrolling one chat.

Will I lose chat history if I switch to WhatsApp Web?

No messages are deleted, but WhatsApp says the desktop app syncs more message history than WhatsApp Web. Your full history stays on your phone.

Can I use WhatsApp Web and the desktop app at the same time?

Yes. Each one is a separate linked device, and WhatsApp allows up to four linked devices alongside your phone.
