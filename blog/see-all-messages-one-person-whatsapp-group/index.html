How to see all messages from one person in a WhatsApp group

Published November 13, 2026

Someone on r/whatsapp asked: "Is there a way I can see all messages of one person in a group chat, without having to scroll thru the entire chat?" The first reply was one word: "No". Inside WhatsApp, that is about right. Search looks for words in messages, and WhatsApp's Help Center lists search by keyword, search by date and a way to find groups you share with someone. It lists no filter by sender. You can still get one person's messages together by exporting the group and searching the file.

What WhatsApp search can do in a group

  • Find a word or phrase. Open the group, click the search icon and type. Each result opens that message in the chat.
  • Jump to a day. In the same search, click the calendar and pick a date.
  • Find groups you share with someone. Type a contact's name in the search at the top of the Chats tab, and the groups you are both in appear under Groups in common.

Typing a person's name inside the group finds messages where the name appears in the text, such as a reply that mentions them. It doesn't gather the messages they wrote. If what you want is the messages where someone tagged you, the Mentions and replies filter is quicker.

1. Export the group

WhatsApp Web, or the Windows or Mac app. Open the group, open the menu at the top of the chat, click Export chat, choose All messages or Custom date range, then click Export. You get a ZIP file (WhatsApp's steps).

Android. Open the group, tap the three-dot menu > More > Export chat, tap Without media and pick where to send it (WhatsApp's Android steps).

iPhone. Open the group, tap the group name at the top, then Export chat and Without media, and save it, for example to Files (WhatsApp's iPhone steps).

Without media is enough here. You only need the text file inside the ZIP.

2. Search the file for their name

Open the text file on a computer. Each message starts with the date, the time and the sender's name, so the file reads like a log. Press Ctrl+F (Cmd+F on Mac) and type the person's name followed by a colon, for example Ana:. The colon skips the messages where someone else only mentions Ana.

Use the name as it appears in your phone's contacts. If you haven't saved the person, look for their phone number instead. A message that runs over several lines carries the name on its first line only, so read on to the next dated line before you move to the next match.

3. Or list only their messages in a spreadsheet

Ctrl+F still makes you jump from match to match. To see one person's messages in a single list, you need the chat in columns with the sender in its own column. Once you have that, a filter on the sender column hides everyone else (Excel, Google Sheets). WhatsApp's export is a plain text file, so splitting it into columns takes some work; the box at the end of this post covers one way to get a CSV with a sender column from WhatsApp Web.

What the export leaves out

  • Media. WhatsApp says an export from the computer has no media, and a phone export puts it in separate files.
  • View once messages, and on WhatsApp Web, disappearing messages.
  • Everything, if the group uses Restricted chat. WhatsApp's Help Center says people in a restricted chat can't export it. See what Restricted chat blocks on WhatsApp Web.
  • Older messages WhatsApp Web never loaded. See why WhatsApp Web isn't showing old messages.

To find one message in a busy group rather than everything a person said, our post on finding important messages buried in a WhatsApp group covers search, dates, stars and pins.
