WhatsApp exported chat viewer: how to read the .txt file you got

Published November 18, 2026

You don't need a special viewer for a WhatsApp chat export: unzip it if it came as a ZIP, then open the .txt file inside with any text editor or drag it into a browser tab. What you get is a plain log of messages, one after another, with the photos and voice notes either as separate files or missing.

That is fine for finding one message. It is hard going for reading a long conversation, sharing it with someone, or printing it. This post covers how to read the file you already have, what WhatsApp leaves out of it, and a second way to get a copy from WhatsApp Web that opens as a readable page.

What WhatsApp's export actually gives you

WhatsApp's Help Center describes the export slightly differently on each device. All three versions agree on one thing: the export "can't be re-imported because it's a text file and not a backup file."

  • Android. Open the chat, tap More options > More > Export chat, then choose Without media or Include media and pick an app to send it with, such as Gmail or Quick Share. With Include media, the most recent media is added as attachments.
  • iPhone. Tap the contact or group name > Export chat. If the chat has media, you choose With all media, With selected media or Without media. The export is a ZIP file. View once messages are not exported.
  • WhatsApp Web, Windows and Mac. Open the chat menu > Export chat, choose All messages or Custom date range, then Export. It is saved as a ZIP file. Media isn't included, and view once and disappearing messages aren't exported.

How to read the exported .txt file

  1. Get the file onto your computer. If you exported from the phone, email it to yourself or save it to Files or Drive, then download it.
  2. Unzip it. On Windows, right-click the ZIP and choose Extract All. On a Mac, double-click it. Inside is the .txt file, plus any media you chose to include.
  3. Open the .txt. Notepad, TextEdit or any code editor will do. You can also drag the file into a Chrome window, which is handy for printing it later.
  4. Search instead of scrolling. Press Ctrl+F (Cmd+F on a Mac) and type a word, a name or a date you remember. In a long group chat this is the fastest way to reach the part you need.
  5. Keep the media files in the same folder as the .txt. The text and the photos are separate files, so if you move one, move the others with it.

If you might need the file as a record later, don't save edits over the original. Make a copy first if you want to mark it up.

Why it's hard to read

The .txt is a log: date, time and name on each line, then the message. There are no bubbles, no colours for who said what, and no pictures in place. A year of a busy group chat can be thousands of lines long.

Some things are missing entirely:

  • Media. The computer export has none. A phone export puts media in separate files next to the text.
  • View once messages, on every device, and disappearing messages in a WhatsApp Web export.
  • Chats with Restricted chat turned on. WhatsApp's restricted chat article says people in such a chat "can't export the chat". In a group, admins turn it on. In a one-to-one chat, either person can.

If you need the export to look like the chat, or you're going to print it, our guide to printing a WhatsApp chat or saving it as a PDF walks through the printing side.

Which copy to keep

  • For a record you might need later, keep WhatsApp's own export untouched, with its media files.
  • For reading, sharing or printing, an HTML copy is easier on the eyes.
  • For totals or lists, such as amounts in an order thread, a CSV opens in Excel or Google Sheets.

Neither kind of export is a backup. To move your chats to a new phone, use WhatsApp's chat backup; our post on WhatsApp cloud storage backups covers the newest option.

FAQ

Is there an official WhatsApp exported chat viewer?

No. WhatsApp's Help Center describes the export as a text file that can't be re-imported into WhatsApp. You read it with a text editor or a browser.

Why is my WhatsApp export a ZIP file?

WhatsApp says exports from the iPhone, WhatsApp Web and the Windows and Mac apps are saved as a ZIP file. Unzip it to get the .txt file and any media you included.

Can WA Folders open my WhatsApp .txt export?

No. WA Folders makes its own export from the chat open on WhatsApp Web, as HTML, CSV, Markdown or JSON. It doesn't open or convert WhatsApp's .txt files.

Why are photos missing from my exported chat?

An export from WhatsApp Web or the computer apps never includes media. On the phone, choose Include media (Android) or With all media (iPhone) when you export. To keep the actual photo, voice note, video and document files from a WhatsApp Web chat, see how to save photos, voice notes and files from a WhatsApp Web chat.

Why can't I export a WhatsApp chat at all?

The chat may have Restricted chat turned on. WhatsApp says people in a restricted chat can't export it, and that includes WhatsApp Web.
