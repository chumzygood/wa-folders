WhatsApp Web chat themes: how to set one for all chats or just one

Published November 12, 2026

WhatsApp Web now has chat themes: open Settings, then Chat theme, and pick one of 27 themes, or set a different theme for a single chat from that chat's info screen. Only you see the theme you choose.

WABetaInfo reported on October 15 that the themes are rolling out to some WhatsApp Web beta users and will reach more accounts over the coming weeks. The same update is on the WhatsApp app for Windows, which uses the web client for this. If you don't see the option yet, your account hasn't been switched on.

What a chat theme changes

A theme sets two things at once: the chat color and the wallpaper behind your messages. You don't have to pick them separately. WhatsApp's Help Center describes it the same way for the phone apps: "A theme sets both the chat wallpaper and chat color."

Phone users have had themes since WhatsApp announced them in February 2025. The web version is the newer part.

How to set a theme for all chats on WhatsApp Web

Per WABetaInfo's walkthrough:

  1. Open Settings in WhatsApp Web.
  2. Open the Chat theme section.
  3. Pick one of the 27 themes in the grid. Each tile shows a small preview of its wallpaper and color.
  4. Check the live preview on the right side of the screen, then save.

A theme picked here applies to all your conversations right away. To go back to the normal look, choose the first option at the top of the page, which restores the default theme.

You can also skip the presets and choose a wallpaper and a color yourself. You can also choose whether the default wallpaper shows the classic doodle pattern.

How to give one chat its own theme

Open the chat, open its chat info screen, and choose a theme there. That chat keeps its own theme while the rest use your default.

This is handy when two chats look alike. If your family group and your work group have similar names or the same people, a bright theme on one makes it obvious which one you're typing into before you hit send.

Can the other person see my theme?

No. WABetaInfo says only the person who sets a chat theme can see it. Everyone else in the chat sees their own theme, or the default look if they haven't picked one. WhatsApp's own blog said the same when themes launched on phones: "your chat themes are only visible to you."

WABetaInfo also says WhatsApp is testing a way to sync your theme and wallpaper with the other person. It isn't available yet.

Themes color a chat; they don't sort your chat list

A theme only shows once a chat is open. Your chat list on the left looks the same, so a theme won't help you find the chat in the first place. For that you need some way to group chats.

On the phone, WhatsApp has Lists. On WhatsApp Web, WhatsApp's own options are the built-in filters plus pinning and marking chats unread. If you're trying to keep work and personal chats apart, folder tabs do that job and a theme makes the open chat easy to recognize.

FAQ

Where are chat themes on WhatsApp Web?

In Settings, under Chat theme, per WABetaInfo. If you don't see that section, the feature hasn't reached your account yet. It's rolling out to some beta users first.

How many chat themes does WhatsApp Web have?

27, according to WABetaInfo's October 15 report. Each one changes both the chat color and the wallpaper.

Can I set a different theme for one chat?

Yes. Open that chat's info screen and pick a theme there. Other chats keep the default theme you set in Settings.

Does the other person see my chat theme?

No. Only you see the theme you set. The other person sees their own theme or the default look.

Is the chat theme the same on my phone and on WhatsApp Web?

WhatsApp hasn't said that your theme syncs between your phone and your computer. WABetaInfo says a feature to sync your theme and wallpaper with other people is being tested but isn't available yet.
