How to print a WhatsApp chat or save it as a PDF

Published November 12, 2026

WhatsApp has no Print button, on the phone or on WhatsApp Web. To get a chat on paper, you export it first and then print the exported file from a computer. The export is a plain text file, so the printout reads like a log with a date, time and name on each line. It won't look like the green and white bubbles on your screen. If the layout matters, screenshots are the other option.

1. Export the chat

WhatsApp Web, or the Windows or Mac app. WhatsApp's Help Center gives these steps:

  1. Open the individual or group chat.
  2. Open the menu at the top of the chat and click Export chat.
  3. Choose All messages or Custom date range.
  4. Click Export.

The chat is saved as a ZIP file. WhatsApp says media isn't included in an export from the computer, and view once and disappearing messages aren't exported.

Android. Open the chat, tap the three-dot menu > More > Export chat, then tap Without media or Include media and pick where to send it, such as Gmail or Quick Share (WhatsApp's Android steps). With Include media, the most recent media is attached as separate files.

iPhone. Open the chat, tap the contact's or group's name at the top, then Export chat. If the chat has media, you choose With all media, With selected media or Without media. Then choose where it goes, for example Save to Files (WhatsApp's iPhone steps). The export is a ZIP file.

For printing, Without media is enough. Photos and voice notes come out as separate files, and the text file is what you print.

2. Get the file onto a computer

If you exported from your phone, email the file to yourself or save it to cloud storage, then download it on the computer. Open the ZIP and take out the text file inside. WhatsApp notes that this file can't be imported back into WhatsApp, because it is a text file and not a backup.

3. Print it, or save it as a PDF, from Chrome

  1. Drag the text file into a Chrome window, or open it in any text editor.
  2. Press Ctrl+P on Windows (Cmd+P on Mac).
  3. Pick your printer as the destination, or pick Save as PDF to keep a PDF copy (Chrome Help).
  4. Click Print or Save.

A long group chat can run to hundreds of pages. On WhatsApp Web, Custom date range lets you export only the days you need, which keeps the printout short.

If Export chat is missing

Someone on r/whatsapp wrote that "sometimes the export button does not give me the option to export with or without media and doesn't even let me download it to my device." One documented reason for a missing or blocked export is Restricted chat, which replaces the older Advanced chat privacy setting. WhatsApp's Help Center says that when it is on, people in the chat can't export the chat, can't save its media to their gallery automatically, and can't use linked devices for that chat. In a group, admins turn it on; in a one-to-one chat, either person can. So WhatsApp Web won't get around it either. Our post on what Restricted chat blocks on WhatsApp Web has the details.

What the printout leaves out

  • Photos, videos, documents and voice notes. A computer export has no media at all, and a phone export puts media in separate files.
  • View once messages, and on WhatsApp Web, disappearing messages.
  • Older messages WhatsApp Web never loaded. If old history is missing on the computer, see why WhatsApp Web isn't showing old messages.
