How to stop WhatsApp Desktop and Web from auto-downloading files

Published November 15, 2026

To stop WhatsApp on your computer from saving files on its own, open Settings, go to Chats > Media auto-download (on the Windows app, Storage > Automatic downloads), and untick photos, audio, videos and documents. After that, a file sits in the chat until you click it.

The rest of this post covers where the switch hides in each version, what still gets saved after you turn it off, and why this came up again this week.

Why people are turning it off this week

On November 14, 2026, TokenPost reported that crypto trader Harley Lewis Foote said a WhatsApp payload gave an attacker remote access to his computer, and that it downloaded without him clicking anything. He said the attacker took nearly all his funds and got into his email, passwords and X account. In a follow-up post, according to TokenPost's Chinese edition, Foote said auto-download was switched on in his WhatsApp Desktop app.

That is one person's account. The reports we read don't say what the file was or how it ran, and we can't confirm the details. The setting he pointed to is real, though, and on a work computer there are good reasons to switch it off anyway: a busy group can fill your disk, and a file you never chose to download is a file you never looked at first.

Turn off auto-download in WhatsApp Web or the Mac app

WhatsApp's help page on auto-download gives these steps for Web and Desktop:

  1. Click Settings or your profile picture, then Chats.
  2. Click Media auto-download.
  3. Untick the types you don't want saved on their own: photos, audio, videos, documents.

If you only change one box, make it Documents. WhatsApp's list has photos, voice messages, videos and documents, so a ZIP file or an installer counts as a document. Leaving photos on means chats still show pictures without an extra click.

Turn off auto-download in the Windows app

The Windows app puts the same switches in a different place. I Have A PC's walkthrough lists:

  1. Click the gear icon at the bottom left of the WhatsApp window.
  2. Open Storage.
  3. Under Automatic downloads, turn off Photos, Audio, Videos and Documents.

The same walkthrough says all four were switched on by default when it was written. If you've never opened this screen, assume yours are on.

If your version has no Storage screen, look under Chats for Media auto-download, which is where WhatsApp's own help page puts it.

If the Windows app won't open or its settings won't load, see WhatsApp Desktop not working on Windows.

What still lands on your computer

Turning off auto-download doesn't mean nothing is ever saved. WhatsApp's page on downloading media on Mac and Windows says:

  • An image isn't saved permanently on your computer until you download it by hand (click the file, open the menu, Save to downloads).
  • Files you open without downloading are stored in a cache folder.

So opening a file still puts a copy on the machine. The setting stops the copies you never asked for. It doesn't make opening unknown files safe.

Make Chrome ask before saving anything

If you use WhatsApp Web in Chrome, manual downloads go through Chrome. Per Chrome's help page, two settings help here:

  • Ask where to save each file. Open Chrome's menu > Settings > Downloads and turn on Ask where to save each file before downloading. Every download then needs one more click from you, which is a useful pause.
  • Stop files opening by themselves. In Chrome's recent downloads list, right-click a file. If Always open files of this type is ticked, untick it.

Chrome also warns before saving program files such as .exe, .dll and .bat. Google's advice is to click Discard if you're not sure what the file contains.

Before you open a file someone sent you

A few habits cover most of the risk:

  • If the file came from a number you don't know, or from a friend who doesn't usually send files, ask them in a separate message or call whether they meant to send it.
  • Be suspicious of ZIP, RAR, ISO, EXE and script files in a chat about an invoice, a parcel or a job offer. We covered that pattern in fake invoice ZIP files on WhatsApp.
  • On Windows, right-click the file in File Explorer and choose Scan with Microsoft Defender (on Windows 11 it may be under Show more options). Microsoft's steps show the result in Windows Security.

If you think a file already ran, check which computers are linked to your account and log out the ones you don't recognise. Our post on malware and WhatsApp Web linked devices has the steps. Then change the passwords you use on that computer from a different device.

FAQ

How do I stop WhatsApp Desktop from downloading files automatically?

Open Settings and go to Chats > Media auto-download, then untick photos, audio, videos and documents. On the Windows app the same switches may be under Settings > Storage > Automatic downloads.

Does WhatsApp Web download files automatically?

WhatsApp's help page lists the same Media auto-download setting for WhatsApp Web, under Settings > Chats. Untick the media types you don't want saved without a click.

Will I still see photos and files in my chats?

Yes. The files stay in the chat, and you click one to download or open it. WhatsApp says files you open without downloading are kept in a cache folder.

Is turning off auto-download enough to stay safe?

It stops files from being saved without your choice. It doesn't make a bad file safe once you open it, so check unexpected files with the sender and scan them before opening.
