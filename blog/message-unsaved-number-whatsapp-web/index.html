How to message a number you haven't saved from WhatsApp Web

Published November 23, 2026 · Em português

You don't have to add the number to your contacts first. WhatsApp's click-to-chat feature lets you start a chat with someone as long as you know their phone number and they have an active WhatsApp account. Clicking the link opens the chat automatically. It works on your phone and on WhatsApp Web (WhatsApp Help Center).

Make a click-to-chat link

WhatsApp's format is https://wa.me/ followed by the full number in international format. Leave out zeroes, brackets and dashes (WhatsApp Help Center).

  • Use: https://wa.me/1XXXXXXXXXX
  • Don't use: https://wa.me/+001-(XXX)XXXXXXX

WhatsApp's own "use" example also leaves out the plus sign. The digits after wa.me/ start with the country code, then the rest of the number. A Brazilian number, in WhatsApp's Portuguese Help Center example, looks like https://wa.me/55XXXXXXXXXXX.

Open the link in the browser where you use WhatsApp Web. If that number has an active WhatsApp account, the chat opens.

Add a message that's already typed

To have a message waiting in the text field when the chat opens, add ?text= and the URL-encoded text (WhatsApp Help Center):

https://wa.me/1XXXXXXXXXX?text=I'm%20interested%20in%20your%20car%20for%20sale

WhatsApp also lets you make a link with only a pre-filled message and no number: https://wa.me/?text=urlencodedtext. After you click it, you are shown a list of contacts to send the message to. That form is for people already in your contacts, not for a number you haven't saved.

If the chat doesn't open

  • Check the format. The number has to be in international format, with the country code and without zeroes, brackets or dashes (WhatsApp Help Center).
  • The account has to be on WhatsApp. Click to chat only works if the person has an active WhatsApp account (WhatsApp Help Center).

After the chat is open

You can write and send the message as usual. Until you save the person, WhatsApp Web shows their phone number instead of a name. You can add them as a contact from that chat if you want the number saved (WhatsApp Help Center).

When you first message someone who isn't in your contacts and may be someone you don't know, WhatsApp may show extra details, including whether you have groups in common and the country the number is registered in, so you can decide whether to continue or cancel the chat (WhatsApp Help Center).
