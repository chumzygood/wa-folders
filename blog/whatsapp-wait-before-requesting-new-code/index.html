WhatsApp says wait before requesting a new code? What to do

Published November 22, 2026

You're trying to log back in to WhatsApp, the code hasn't arrived, and now the app shows a countdown before it will send another one. You tap again when it hits zero, and the next countdown is longer.

That's how the system is built. WhatsApp limits how often a phone number can request a verification code, and according to its help center, each new request makes the wait before the next one longer. Requesting again too soon can extend it. So the fastest way back in is usually to slow down.

What the timer means

The countdown is a limit on how often your number can request a code. WhatsApp says the limit is there to protect accounts, since a code is the key to logging in.

A few things follow from that:

  • There's no shortcut. WhatsApp's registration help page says that after "You have guessed the code too many times" you have to wait the stated time, and there's no way to make it faster. Reinstalling the app won't skip it.
  • Wrong guesses count against you. The logged-out help page says not to guess the code, or you'll be locked out for a period of time.

How long the normal wait is

For a first-time registration, WhatsApp says to wait for the five-minute timer to finish. When you're logging back in to an existing account, it says the wait may take up to 10 minutes. People report much longer waits after repeated requests, up to several hours (the r/whatsapp post further down describes a 7-hour one). WhatsApp doesn't publish an exact schedule, so be wary of any site that claims to know it.

What to do, in order

Do these while the timer runs, so that when it ends you only need one try.

  1. Check the number you typed. Use the full international format with the country code and no leading zero. WhatsApp's example for the US is +1 408 XXX-XXXX. Don't edit the number while a timer is running.
  2. Make sure the SIM can receive texts. Send an SMS to your own number from another phone, typed exactly as you entered it in WhatsApp. If it doesn't arrive, the problem is your carrier or signal, and your carrier is the one to call.
  3. Turn the phone off for 30 seconds and back on. That's on WhatsApp's own troubleshooting list.
  4. Turn on Wi-Fi Calling if your signal is weak. WhatsApp suggests it for registration problems on bad networks, since it lets texts and calls come in over Wi-Fi.
  5. When the timer hits zero, request once. If the SMS still doesn't come, wait for that timer to finish too, then tap Call me. An automated voice reads out the 6-digit code.
  6. Look for the email option. If you're logging back in to an existing account and you added and verified an email address in WhatsApp before, you may be offered the code by email. It isn't available for first-time registration.
  7. Use the code quickly. The porting help page says a code is valid for a limited time and works only once.

If you just moved your number to a new carrier or SIM, check that the number is fully active on the new network first. WhatsApp says codes can't be delivered until it is, and that the SMS can take a few minutes to arrive after porting.

If you didn't ask for any of these codes

Sometimes the timer isn't your doing. Someone else can request codes for your number, and the limits still apply to you. In late October, a WhatsApp Business user described on r/whatsapp getting verification code emails they never asked for, then a notice that someone was trying to move the account to another phone, then being logged out and stuck on a timer that kept restarting.

If that sounds familiar, follow WhatsApp's compromised account steps:

  • Never share a code with anyone who asks, including friends or family.
  • Re-register with the 6-digit code sent to your number. That logs everyone else out. Changing a password does not.
  • If you're asked for a two-step verification PIN you didn't set, someone else may have set it. Without the PIN, WhatsApp says to wait 7 days and try again.
  • Warn people you chat with, because whoever had the account could message them as you.

What happens to WhatsApp Web when you get back in

Re-registering your number logs out every device linked to the account. WhatsApp's recovery page says this happens automatically when you enter the 6-digit code. So once your phone is working again, your computer will show the QR code screen.

To link it again, open WhatsApp on your phone, go to Settings (iPhone) or the three-dot menu (Android), tap Linked devices, then Link a device, and scan the QR code on web.whatsapp.com. While you're on that screen, check the list of linked devices, and log out of anything you don't recognize.

If the QR code won't scan, see what to do when the WhatsApp Web QR code won't scan. If you got logged out and your chats seem to be missing, this guide on chats after logging out covers what comes back and what doesn't.
