How to turn disappearing messages on or off in WhatsApp Web

Published November 2, 2026

WhatsApp Web has the same disappearing messages setting as the phone app. When it's on, new messages in a chat delete themselves after 24 hours, 7 days or 90 days. You can turn it on for one chat, for a group, or as the default for every new chat you start.

The timer only covers messages sent after you turn it on. WhatsApp's Help Center says it "applies to new messages in the chat only, not to previous messages you've sent or received."

Turn on disappearing messages in one chat

  1. Open the chat.
  2. Click the contact's name at the top.
  3. Click Disappearing messages. If WhatsApp asks, click Continue.
  4. Pick 24 hours, 7 days or 90 days.
  5. Click the back arrow to save.

Either person in a one-to-one chat can do this.

Turn it off in one chat

Same steps, but pick Off in step 4. Anyone in the chat can turn it off at any time.

Before you do, keep any messages you want to hold on to (see below). The Help Center says that once you turn disappearing messages off, you can't keep them anymore.

Set a default timer for all new chats

  1. Click Settings (the gear), then Privacy.
  2. Click Default message timer.
  3. Pick 24 hours, 7 days, 90 days or Off.
  4. WhatsApp then offers to apply the timer to chats you already have. Click the chats you want and click the check mark. If you don't want to change any existing chats, click the back arrow.

The default only affects new one-to-one chats, plus any existing chats you pick in step 4.

Groups

In a group, any member can turn disappearing messages on, unless an admin has limited it to admins only in the group settings.

  1. Click the group chat.
  2. Click the group name to open Group info.
  3. Click Disappearing Messages. If asked, click Continue.
  4. Pick 24 hours, 7 days or 90 days, or Off to turn it off.

You can also turn it on while creating a new group.

Keep a message so it doesn't disappear

If a disappearing chat has one message you need, like an address or a code, you can keep it before the timer runs out:

  • Click the message, or the menu arrow on it, and click Keep.
  • To see everything you kept in a chat, open the chat info and click Kept messages.

A kept message stays visible to everyone in the chat. If someone keeps a message you sent, you get a notification, and you can unkeep it: click the menu on the message, then Unkeep and OK. Once the sender unkeeps a message, nobody else in the chat can keep it again. Group admins can limit keeping to admins only. You can't unkeep a message more than 25 days after its timer has passed.

FAQ

If I turn on disappearing messages, will my old messages vanish?

No. WhatsApp says the timer applies to new messages only.

Can the other person turn it off?

Yes. In a one-to-one chat either person can turn it on or off. In a group any member can, unless an admin limited it to admins.

What's the difference between the default timer and the per-chat setting?

The default timer applies to new one-to-one chats you start after setting it. The per-chat setting changes one chat or group at a time.
